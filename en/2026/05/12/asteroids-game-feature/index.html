🎮 博客新增纸飞机射击游戏！网页元素破坏者上线

🎮 博客新增纸飞机射击游戏！网页元素破坏者上线

按下 G 键开启游戏，用 WASD / 方向键控制飞机，空格键发射子弹，尽情破坏网页上的一切吧！💥

功能简介

这次给博客添加了一个有趣的彩蛋功能 —— 网页纸飞机射击游戏！灵感来自于 live2d-widget 项目中展示的 Website Asteroids。

操作说明

按键 功能
G 开启 / 关闭游戏模式
W / ↑ 飞机向上移动
S / ↓ 飞机向下移动
A / ← 飞机向左移动
D / → 飞机向右移动
Space（空格） 发射子弹

游戏特色

  • ✨ 发光三角飞船 — Canvas 绘制的霓虹风格飞机，带有引擎火焰特效
  • 🔫 金色光弹 — 带有发光效果的子弹，有射程限制和射击冷却
  • 💥 爆炸粒子 — 击中元素时产生彩色碎片飞散效果
  • 📊 计分系统 — 实时显示击毁数量，得分时有弹跳动画
  • 🎯 精确碰撞 — 支持行内元素（<code>、<strong>、<em>等）的精确打击

技术实现

核心技术栈

  • HTML5 Canvas — 用于绘制飞机和子弹
  • DOM API — getBoundingClientRect() 获取元素坐标
  • requestAnimationFrame — 60fps 游戏循环
  • 事件监听 — 键盘控制、窗口滚动/resize 响应

碰撞检测优化

开发过程中遇到了一些挑战：

  1. 滚动导致坐标失效 — 最初缓存了元素坐标，但滚动页面后坐标就失效了。解决方案：碰撞检测时实时获取元素位置。

  2. 子弹跳过小元素 — 子弹移动速度（10px/帧）快于行内元素宽度，导致直接穿过。解决方案：采用扫掠碰撞检测，沿子弹路径细分采样。

  3. 性能优化 — 全量 DOM 查询开销大。解决方案：缓存可破坏元素列表，每 10 帧刷新一次。

代码架构

可破坏元素

游戏支持破坏以下 HTML 标签元素：

  • 标题：h1 ~ h6
  • 文本：p, span, strong, em, b, i, u, mark
  • 链接：a
  • 代码：code, pre
  • 列表：li, dt, dd, td, th
  • 引用：blockquote, q, cite
  • 其他：img, button, label, figure, figcaption

🚫 为保护页面结构，body、script、style、header、footer、main 等核心容器不会被破坏。

使用方法

在博客任意页面按下 G 键即可开启游戏。飞机默认出现在屏幕中央，你可以：

  1. 用方向键或 WASD 移动飞机
  2. 瞄准页面上的文字、图片、按钮等元素
  3. 按空格键发射子弹击毁它们
  4. 再次按 G 键退出游戏
