# 同主题文章聚合「磨砂抽屉」设计规格

- 日期：2026-10-30
- 责任人：蔡振辛
- 状态：设计待评审（未进入实现）
- 方案：方案 B · 磨砂浮层「文集抽屉」（Glass Drawer）

---

## 1. 背景与目标

当前 Fluid 主题首页 [index.ejs](../../../themes/fluid/layout/index.ejs) 将每篇文章渲染为独立卡片（封面 + 标题 + 200 字摘要 + 元信息）。同一专题的多篇长文（如 2026-10-25 的「夜谈」三篇）会被打散成平级卡片，读者无法感知它们属于同一个「连续阅读单元」。

**目标**：为显式声明的同主题文章提供聚合入口——首页收拢为一张「专题卡」，悬停时浮出磨砂面板列出全部条目，配合柔和不突兀的光晕渐变做视觉引导。

**成功标准**：

- 同主题（`series` 相同）且 ≥ 2 篇的文章，在首页聚合成 1 张专题卡；
- 悬停 / 键盘聚焦可平滑展开抽屉，列出该专题全部条目；
- 光晕柔和克制，不干扰正文阅读；
- 不影响未声明 `series` 的普通文章渲染。

## 2. 范围（MVP）

包含：

- 首页 `index` 分页内的专题聚合；
- 显式 `series` 字段判定；
- hover + focus 双通道展开、`Esc` 收起；
- 窄屏降级为点击展开；
- 深色模式配色。

不包含（非目标）：

- 分类页 / 标签页 / 归档页的聚合（后续可复用同一 partial）；
- 拖拽、筛选、排序等高级交互；
- 自动聚合（按分类自动成组）；
- 文章详情页的「同专题延伸阅读」。

## 3. 聚合判定

- **聚合键**：front-matter 的 `series`（字符串）。同名 `series` 视为同一专题。
- **阈值**：同组文章数 ≥ 2 才生成专题卡；单篇保持原有卡片。
- **排序**：组内按 `date` 升序（贴合按序阅读），首篇作为卡片主展示。
- **示例**：为「夜谈」三篇各加 `series: 夜谈`。

```yaml
# 示例（不改正文，仅加字段）
series: 夜谈
```

## 4. 数据结构

在首页渲染时按 `series` 分组：

```text
groups = {
  [series]: { topicName, postCount, posts: Post[] }  // posts 按 date 升序
}
```

渲染顺序：保持原首页整体时间顺序不变，仅将同一 `series` 的卡片收拢为一张专题卡。具体口径：

- **卡片在时间流中的位置**：取该组「最新一篇」在首页时间线的位置（读者看到的是最近更新点）；
- **卡片主展示内容**：取该组「最早一篇」作为起点标题与摘要（契合按序阅读）；
- 其余非专题文章位置与顺序不变。

> 注：抽屉内「阅读时长」若无现成 helper，可按正文字数估算（如 300 字/分钟），或先以「篇数 / 日期」替代，避免引入额外依赖。

## 5. 组件与文件

| 类型 | 路径 | 作用 |
|------|------|------|
| Partial | `themes/fluid/layout/_partials/topic-card.ejs` | 渲染专题卡与抽屉结构 |
| 逻辑修改 | `themes/fluid/layout/index.ejs` | 分组、判断是否渲染专题卡 |
| 样式 | `source/css/topic-card.css` | 磨砂、光晕、动效、暗色模式 |
| 配置挂载 | `themes/fluid/_config.yml`（`custom_css`） | 引入样式 |

原则：尽量不侵入 Fluid 核心，逻辑集中在 partial 与样式文件。

## 6. 交互规格

| 项 | 规格 |
|----|------|
| 触发 | `mouseenter` 展开；`focus-within`/键盘 `focus` 展开 |
| 收起 | 移出给 160–200ms 宽限；`Esc` 立即收起 |
| 展开动画 | 220–280ms；面板 `scale 0.98 → 1` + `translateY(8px → 0)` + `opacity 0 → 1` |
| 条目 stagger | 每项延迟约 30ms，按时间顺序出现 |
| 缓动 | spring 风格（如 `cubic-bezier(0.22, 0.61, 0.36, 1)`），无生硬跳变 |
| 触屏/窄屏 | 无 hover 环境降级为点击切换，`aria-expanded` 同步 |
| 点击条目 | 直接跳转文章（沿用 `post_url_target`） |

## 7. 视觉规格

- **专题卡**：磨砂质感，专题名 + `×N` 篇数徽标 + 首篇标题/短摘要；左侧细强调线。
- **抽屉面板**：半透明 + `backdrop-filter: blur` + 1px 极细边框；条目 = 序号 + 标题 + 日期 + 阅读时长。
- **柔光晕**：卡片/面板边缘向外扩散的主题色光，大 `blur`、低 `alpha`（约 8–12%），缓慢呼吸；仅作引导，不进入正文对比度区。
- **条目 hover**：左侧浮出细彩色指示条，标题轻微提亮。
- **字体/留白**：字号克制、行距宽松、留白充足，避免重阴影与高饱和。
- **暗色模式**：面板底加深、光晕 alpha 降低、边框透明度下调，保证对比度。

## 8. 可访问性与响应式

- `role="button"` + `aria-expanded` 反映展开态；`aria-controls` 指向抽屉。
- 键盘可聚焦并展开，焦点有可见描边。
- 窄屏（< 768px）抽屉改为点击展开，宽度自适应、可滚动。
- 尊重 `prefers-reduced-motion`：减少/关闭渐变与 stagger。

## 9. 边界情况

- 单篇专题：不聚合，按原卡片。
- 同名专题跨分页：仅聚合当前页内的同组文章。
- 组内文章数量较多（> 6）：抽屉内滚动，不撑高页面。
- 深浅色切换、字体缩放、抽屉与相邻卡片重叠层叠顺序（z-index 需高于相邻卡片、低于全局导航）。

## 10. 验收标准

1. 给「夜谈」三篇各加 `series: 夜谈` 后，首页出现 1 张专题卡，抽屉含 3 条按时间升序的条目。
2. 悬停展开平滑无抽搐，移出 200ms 内收起；`Esc` 收起。
3. 键盘可聚焦展开，`aria-expanded` 正确切换。
4. 光晕不遮挡正文，深色模式对比度正常。
5. 未声明 `series` 的文章渲染与改动前一致。
6. 窄屏点击可展开，抽屉可滚动。

## 11. 风险与取舍

- `backdrop-filter` 在旧浏览器表现降级为纯半透明底（可接受）。
- 首页分组逻辑改动需回归验证分页与排序，避免打乱原有时间流。
